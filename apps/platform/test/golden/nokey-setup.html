Set up Example X

  1. Make its database and service in Render

    1. Render → New → Postgres. Name base-win-x-db, region Oregon, PostgreSQL 16, the plan named in render.yaml (basic-1gb).
    2. Render → New → Web Service → this repository. Name base-win-x, language Docker, branch production, region Oregon, instance Starter. Under Advanced, health check path /api/health.
    3. On that page, Environment → Add from .env → paste this block: 
      NODE_ENV=production
STARBASE_ENV=production
STARBASE_PUBLIC_URL=https://x.base.win
STARBASE_BRAND=base
STARBASE_ORG_NAME="Example X"
STARBASE_JURISDICTION=bc-municipal
STARBASE_PROVINCE=BC
STARBASE_TZ=America/Vancouver
STARBASE_CITY="Exampleton"
STARBASE_SLATES="council:City council"
STARBASE_GEO_BOUNDS=50.6,-120.5|50.8,-120.2
STARBASE_CANDIDATES=none
BASE_PLATFORM_PUBKEY=mkRxeAO03eN7KrA3GBLERx3eKJOHcBJVSdPoSj8hKiU
STARBASE_TWO_STEP_KEY=
GOOGLE_TOKEN_KEY=

      STARBASE_TWO_STEP_KEY and GOOGLE_TOKEN_KEY are empty: press Generate next to each of these two in Render.

    4. Add DATABASE_URL = the database page’s Internal Database URL (copy it across).
    5. Press Create Web Service (or Save and deploy). Wait for “Live”.

    Email, texting and Google come later, from the app’s Settings → Services.

  2. Paste its address

    The address at the top of its Render page, like https://base-win-x.onrender.com
