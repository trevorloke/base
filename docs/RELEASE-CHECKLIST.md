# Release checklist

Lines a release adds when it changes something people outside the team
rely on. Newest first.

## The words the law needs (website languages)

`shared/site/wording.js LEGAL_ENGLISH` holds the English of the lines a
manager approves in each website language (Website → Languages → Words the
law needs). When a release changes one, that line shows in English on the
translated pages until a manager approves new words; a change to
"Authorized by" takes the language off the site until then. Name the
changed keys here, and tell the campaign's managers before the release:

- Legal English first written (authorizedBy, email, sms, newsletter, privacy, donate, join, donateSmall, donateSmallNoLimit, payPageNote, translatedNote, readInEnglish, policyInEnglish). Managers approve them in each language before it is offered.
